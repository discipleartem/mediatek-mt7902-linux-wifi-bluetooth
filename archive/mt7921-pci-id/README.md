# Archive: MT7921 PCI ID 7902 patch

Historical attempt to add PCI ID `0x7902` to in-tree `mt7921`.

**Do not use this for installing Wi‑Fi/Bluetooth on a running system.**

Practical fix: out-of-tree `mt7902e` + `btusb_mt7902` via `./mt7902.sh install-all`.
See [docs/installation.md](../../docs/installation.md).
